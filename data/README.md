Put the PDFs you want to ask questions about in this folder.

Suggested (free, public) mortgage documents:
- CFPB "Your home loan toolkit" (search: "CFPB your home loan toolkit pdf")
- CFPB "Buying a House" / Loan Estimate and Closing Disclosure explainers
- Fannie Mae or Freddie Mac public guideline excerpts

PDFs are git-ignored only if you add them to .gitignore; public docs are fine to commit.
